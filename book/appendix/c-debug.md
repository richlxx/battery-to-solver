# 附录 C 调试清单与失败模式

## C.1 求解失败

| 现象 | 常见原因 | 检查顺序 |
| --- | --- | --- |
| Newton 残差不再下降 | 变量未缩放、容差过严 | 看缩放后的残差范数、条件数 |
| 残差变成 NaN | Jacobian 错误、BV 指数溢出 | 用有限差分对比解析 Jacobian |
| 步长不断缩小 | 刚性误判、事件抖动 | 看步长历史与事件函数 |
| KLU 报奇异 | 缺参考电位、装配漏行 | 检查对角元、零空间、行和 |
| 零电流下电压不等于 OCV | 参数不一致、OCP 插值错误 | 做零电流极限测试 |

## C.2 物理上不合理

| 现象 | 可能原因 |
| --- | --- |
| 总锂量漂移 | 通量边界符号错误、界面面积漏乘 |
| 电压偏低 | 过电位符号、交换电流密度单位 |
| 浓度出现负值 | 网格过粗、时间步过大、未做正性保护 |
| 充放电曲线不对称 | BV 的 $\alpha_a/\alpha_c$ 或符号约定 |

## C.3 验证顺序

1. 零电流 → 端电压等于 OCV。
2. 单颗粒 → 与级数解对比。
3. 小电流 DFN → 与 SPM 接近。
4. 网格/时间收敛 → 观测阶。
5. 与 PyBaMM 对比 → 定位剩余差异。

## C.4 日志建议

- 每个 Newton 迭代打印：缩放后残差范数、步长、线性求解迭代数。
- 每个接受步打印：步长、阶数、事件状态。
- 失败时保存状态向量与矩阵 spy 图。

## C.5 给新手的排错顺序

1. 先确认程序读到的参数对不对（打印出来）。
2. 再确认边界与初始条件（零电流测试）。
3. 最后才怀疑算法；大多数错误在装配，不在 Newton。
