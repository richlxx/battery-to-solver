# 从一块电池到求解器

**写给零数值计算经验的你 · 以 P2D/DFN 为例**

---

如果你没学过数值分析、没写过求解器、对电池的印象还停留在"会没电"，这本书就是为你写的。

我们不假设你会微积分证明，也不要求你懂电化学。你只需要高中数学和好奇心；代码会先跑起来，再慢慢读懂。

## 这本书会带你做出什么

1. **第一小时**：跑通一个小程序，画出电池的开路电压曲线。
2. **第一个里程碑**：亲手算出"把连续方程切成小格子"后的方程组，并验证"账是平的"。
3. **最终成果**：一个能跑的 DFN 求解器，包含手写 BDF 与工业级 IDAKLU 两套后端，并知道如何判断结果可不可信。

## 为什么用电池当例子

电池放电是一个"看得见"的问题：电压、电流、续航都是日常经验。而它背后恰好需要用到数值计算的主要工具：

- 连续方程要**切格子**（离散）
- 每个时间步要**解方程**（线性/非线性）
- 快过程和慢过程混在一起（刚性）
- 结果对不对需要**验证**（守恒、收敛、对比）

把电池算明白，你就同时学会了这些工具；换到热传导、流体、化工，方法是一样的。

## 需要的准备

- 一台能装 CMake 的电脑（Windows/macOS/Linux 均可）。
- 高中数学里的"斜率"和"面积"概念；忘了也没关系，第 1 章会补。
- 能看懂 `if`、`for`、函数调用即可；C++ 语法在附录 B 有 10 页速成。
- 不需要任何数值计算或电池建模经验。
