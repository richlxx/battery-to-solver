## 五种提示框

书中会出现五类标记，帮助你在不打断主线的情况下理解细节：

- **直觉**：用生活语言解释，先建立画面。
- **公式**：完整推导，第一遍可跳过，用到时回查。
- **陷阱**：新手最常犯的错误。
- **动手**：现在就可以运行的命令或修改。
- **检查点**：合上书，试着回答。

## 代码阅读四步法

1. **先运行**：不改任何代码，确认输出与书中一致。
2. **改参数**：只改一个数字，观察结果如何变化。
3. **读关键函数**：从 `main` 进入，只看被调用的那几行。
4. **自己写**：完成章末填空练习，或合上参考代码重写核心循环。

> 看不懂某个函数时，先看它的输入输出，不要逐行死磕。

## 数学记号

- $\partial c/\partial t$：只对时间求变化率，其他方向当作不变。
- $\nabla\cdot N$：通量的净流出；一维时就是 $\partial N/\partial x$。
- 下标 $s$ 表示固相（solid），$e$ 表示液相/电解液（electrolyte），$0$ 表示初始或参考值。
- 向量和矩阵在正文中不特别加粗，靠上下文区分；代码里分别用 `Vec` 和 `SparseMatrix`。

## 公式排版

GitBook 内置 KaTeX，不需要插件。全书统一用两种写法：

| 用途 | 写法 | 说明 |
| --- | --- | --- |
| 行内公式 | `$...$` | 与文字同排，如 `$c_s$`、`$O(h^2)$` |
| 独立公式 | `$$ ... $$` | 单独居中成行，前后各留一个空行 |

块级公式示例（这是源码）：

```md
$$
\frac{\partial c}{\partial t}
= \frac{1}{r^2}\frac{\partial}{\partial r}
\left(r^2 D_s \frac{\partial c}{\partial r}\right)
\tag{3.1}
$$
```

排版规则：

1. `$$` 必须独占一行，前后留空行；不要缩进 4 个空格，否则会被当成代码块。
2. 行内公式的定界符内不加空格：写 `$c_s$`，不写 `$ c_s $`。
3. 多行推导用 `aligned`，换行用 `\\`：

```md
$$
\begin{aligned}
N &= -D_s \frac{\partial c}{\partial r},\\
\frac{\partial c}{\partial t}
&= -\frac{1}{r^2}\frac{\partial}{\partial r}(r^2 N).
\end{aligned}
\tag{3.2}
$$
```

4. 编号手动写 `\tag{章.序号}`，正文用"式 (3.2)"引用。GitBook/KaTeX 不支持 `\label`/`\ref` 自动交叉引用。
5. 表格中的公式避免使用 `|`，需要时写 `\mid` 或 `\vert`，否则会破坏表格。
6. 单位写在正文里（如 5 mV），不要塞进公式；中文不要放进 `\text{}`，KaTeX 对 CJK 字体没有保证。
7. 化学式不使用 `\ce{}`（默认未启用 mhchem），写成文字或普通下标。
8. 正文中的美元金额写成 `\$5`，避免被解析成行内公式。

预览方式：

- GitBook 编辑器与发布站点：原生渲染，以它为准。
- GitHub 网页：支持 `$`/`$$`，可直接查看。
- VS Code：安装 Markdown+Math 或 Markdown Preview Enhanced 插件。
- 旧版 `gitbook-cli` 才需要 `book.json` 里的 `katex` 插件；本项目不使用旧版。

## 单位与符号约定

- 全书使用 SI 单位；放电电流为正。
- 代码内部使用缩放变量（浓度除以参考浓度、电位除以热电压、时间除以扩散时间），缩放因子集中在 `include/dfn/params.hpp`，正文首次出现处会说明。
- 未知量按"先固相、后液相、再电位"打包；该顺序决定第 5 章的稀疏结构。
- 代码标识符英文，讲解中文；代码注释只解释非显然的原因。

## 复现

- 命令默认在仓库根目录执行；每章末尾给出验证命令。
- 书中定量结论由 `tests/` 或 `bench/` 复现，不接受无验证的断言。
