# 第 1 章 数学预备：只讲用得上的

> ★ 核心 · 前置：第 0 章

> 这一章不是数学课，而是一本"按需查阅"的工具手册。每个概念都对应电池里的一个具体东西，看不懂时可以跳回来查。

## 本章你会得到

- 看懂后续章节公式所需的全部数学直觉。
- 用欧拉法手算一步扩散的体验。
- 一张"电池语言 ↔ 数学语言"对照表。

## 1.1 导数：变化有多快

浓度在空间上的变化率就是梯度；梯度越大，扩散越快。只要求理解"斜率"，不要求证明。

## 1.2 积分：把小块加起来

"流入 − 流出 = 积累"就是积分守恒。后面每一章的守恒检验都从这里来。

## 1.3 矩阵与线性方程组

$Ax=b$ 的几何意义：多个方程同时约束一组未知数；消元法的直觉；大部分元素为零时叫"稀疏"。

## 1.4 特征值：哪些误差会被放大（直观版）

不推导定义，只看一个 2×2 例子：为什么有的误差会衰减，有的会爆炸。这是第 7 章"刚性"的伏笔。

## 1.5 微分方程：描述"怎么变"

未知函数和它的导数出现在同一个方程里；初值决定唯一解。

## 1.6 手算欧拉法

用 $y'=-y$ 走两步，亲眼看到"用切线近似曲线"的过程与误差。

## 1.7 偏微分方程：多个方向同时变化

扩散方程、热传导方程；为什么必须切网格才能计算。

## 1.8 电池语言 ↔ 数学语言

| 电池说法 | 数学对象 |
| --- | --- |
| 锂在颗粒里扩散 | 球坐标扩散方程 |
| 电解液里离子迁移 | 对流-扩散方程 |
| 界面反应速率 | 非线性代数方程 |
| 电压 | 两个电位之差 |
| 电量 | 浓度的体积积分 |

## 陷阱

- 把"变化率"当成"变化量"：导数是斜率，不是高度。
- 以为积分就是"求面积"，忘了它同时表示"累积总量"。

## 检查点

1. 浓度梯度为正时，扩散通量朝哪个方向？
2. 为什么"总量守恒"可以写成积分形式？
3. 欧拉法一步之后，误差来自哪里？
