# 第 0 章 从一块电池说起

> ★ 核心 · 前置：无

> 手机剩 5% 时，为什么电压掉得特别快？大电流放电时，为什么"看起来还有电"却放不出来？

本章不推公式，只做三件事：让你看到一条真实的放电曲线是怎么算出来的，给你全书地图，并帮你跑通第一个程序。

## 本章你会得到

- 一个能运行的程序，画出电池开路电压随电量变化的曲线。
- 对"数值计算到底在做什么"的一句话理解。
- 一份属于自己的阅读路线。

## 0.1 三个日常问题

电量低时电压为什么掉得快；大电流为什么可用容量变小；冬天续航为什么缩短。这三个现象背后是同一个模型的不同侧面。

## 0.2 解析解与数值解

能写成公式、代进去就出结果的叫解析解；大多数真实问题没有解析解，只能"切分、近似、迭代"。

## 0.3 数值计算三句话

1. 把连续的东西切成有限块；
2. 每一块用简单关系近似；
3. 让计算机重复计算，并想办法估计误差。

本书后面的所有方法，都是这三句话的展开。

## 0.4 我们要造的东西

最终成果是一条命令画出放电曲线。中间产物：参数表、网格、方程组、线性求解器、时间推进器、验证报告。本章先看成品的"使用说明书"。

## 0.5 全书地图

三段旅程：起步（第 0–2 章）、造求解器（第 3–8 章）、集成与延伸（第 9–10 章）。每章开头都会告诉你"这一章你会得到什么"。

## 0.6 你需要准备什么

高中数学的斜率与面积、能读懂简单循环和函数即可。数学忘了看第 1 章，代码不熟看附录 B，电化学零基础看第 3 章。

## 0.7 动手：第一个程序

`labs/ocv_curve.cpp`：读入一组参数，计算并输出开路电压曲线；用 Python 脚本画图；改一个参数，观察曲线如何移动。

## 直觉：电压为什么随电量下降

锂从负极"搬"到正极，正极的"拥挤程度"变了，电压随之变化。曲线形状由材料的热力学性质决定。

## 陷阱

- 数值计算不是"点一下软件按钮"，你需要知道每一步在近似什么。
- 不需要把第 1 章的公式全部看懂才能继续；先跑起来。
