> 手机剩 5% 时，为什么电压掉得特别快？大电流放电时，为什么"看起来还有电"却放不出来？

## 0.1 三个日常问题

**电量低时电压为什么掉得快？** 负极里的锂快用完了，再往外取锂会越来越"费劲"，负极电位迅速升高，电池电压随之下降。

**大电流为什么可用容量变小？** 反应更快，电极表面的锂来不及补充，过电位变大；电解液里的离子也被快速消耗。这两件事都会让电压提前触底。

**冬天续航为什么缩短？** 锂离子扩散和界面反应都变慢，可用容量和电压都下降。本书的模型假设等温，热的影响只在第 10 章简要提及。

三个现象都指向同一件事：电池的电压不是常数，它由内部的浓度和电位分布决定。要算清楚这些分布，就需要数值计算。

## 0.2 解析解与数值解

如果一个问题能写成公式、代进数字就得到答案，这个公式叫**解析解**。比如匀速运动 $s=vt$，知道速度和时间就能算出距离。

电池不行。锂在颗粒里扩散、在电解液里迁移、在界面上反应，几个过程互相耦合，还带着指数型非线性。我们写不出一个"代进去就出结果"的公式。

于是换一条路：

1. 把连续的空间和时间**切成有限块**；
2. 每一块用**简单关系近似**；
3. 让计算机**重复计算**，并估计误差。

这三步就是数值计算。它给你的不是一个精确公式，而是一串足够准的数字。

## 0.3 数值计算三句话

| 三句话 | 在本书里对应什么 | 章节 |
| --- | --- | --- |
| 切分 | 网格、控制体、离散方程 | 第 4 章 |
| 近似 | 差分、有限体积、误差与阶 | 第 2、4 章 |
| 迭代 | 解线性/非线性方程、推进时间 | 第 5–7 章 |

还差一句：**验证**。不知道近似误差有多大，数字就不可信。第 9 章会用守恒、收敛阶和外部对比三层方法检查结果。

## 0.4 我们要造的东西

最终成果是一条命令画出放电曲线：

```text
参数 → 网格 → 方程 → 线性/非线性求解 → 时间推进 → 曲线与报告
```

中间每一步都会变成一个可运行的模块：参数表、网格、稀疏矩阵、Newton 求解器、BDF 时间推进器、IDAKLU 后端。第 0–2 章先打基础，第 3–8 章逐个造零件，第 9 章把它们装成整机。

### 第 4 步：读代码

打开 `labs/ocv_curve.cpp`，核心只有三个函数：

```cpp
double negative_ocp(double x) {
  const double one_minus_x = 1.0 - x;
  return 0.05 + 0.8 * std::exp(-10.0 * x) + 0.1 * one_minus_x * one_minus_x;
}

double positive_ocp(double y) {
  return 3.9 + 0.2 * (1.0 - y);
}

double open_circuit_voltage(double soc) {
  const double x = 0.10 + 0.75 * soc;
  const double y = 0.90 - 0.80 * soc;
  return positive_ocp(y) - negative_ocp(x);
}
```

逐个看：

- `negative_ocp(x)`：负极的电位。$x$ 是负极的锂含量，越大表示锂越多。锂越少（$x$ 接近 0），指数项让电位迅速升高，这就是低电量端曲线陡的原因。
- `positive_ocp(y)`：正极的电位。$y$ 越大表示锂越多，电位越低；这里用一个简单的线性关系示意。
- `open_circuit_voltage`：把 SOC 映射成两极的锂含量，再用"正极电位减负极电位"得到全电池电压。为什么是相减？因为电压是两点之间的电位差，就像海拔差。

> **注意**：这里的两个 OCP 函数是**示意拟合**，不是真实材料数据。第 3 章会把它写成独立的热力学模块，第 9 章再把几何与输运参数收进参数文件；换真实材料时，OCP 改 `thermo.cpp` 里集中的两个函数。现在只需要看懂"电压 = 正极电位 − 负极电位"这件事。

## 直觉：电压为什么随电量下降

充电时，锂从正极搬到负极；放电时反过来。放电接近尾声，负极里的锂快被搬空，剩下的锂"抓得更紧"，负极电位升高；同时正极越来越满，电位降低。两者一升一降，电压差就迅速缩小。

所以电压从来不是某一个电极的绝对电位，而是**两个电极的差值**。这也是第 3 章要同时求两个电位的原因。

## 陷阱

- **数值计算不是点按钮**：每个结果背后都有切分和近似，误差需要估计。
- **OCV 不是端电压**：有电流时还要减去过电位和欧姆压降，这部分从第 3 章开始出现。
- **曲线平滑不代表模型正确**：平滑只说明程序没崩，是否正确要靠第 9 章的验证。

## 检查点

1. SOC 增加时，负极的锂含量 $x$ 是增大还是减小？为什么？
2. 为什么全电池 OCV 写成"正极 OCP 减负极 OCP"，而不是相加？
3. "切分、近似、迭代"分别对应本书哪些章节？
